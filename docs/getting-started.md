# 开始使用

知序 CPA 免费提供个人非商业学习使用，当前收录会计、税法、经济法。你可以先 [在线体验](https://zhixucpa.cn/preview)，或按下面的步骤在自己的电脑上开始学习。

> 仅供个人学习交流，禁止商业用途。轻一、轻二教材及题目版权归原权利人所有。

## 1. 安装运行环境

安装 **[Node.js 22.13 或更高版本](https://nodejs.org/)**，已有符合版本的可以跳过。这一步只需做一次。

## 2. 下载并解压完整包

**[点击下载完整版](https://github.com/carrotProgrammer/zhixu-cpa/releases/latest/download/zhixu-cpa-full.zip)**，文件名为 **`zhixu-cpa-full.zip`**。

完整解压后，打开其中的 **`zhixu-cpa`** 文件夹。不要在压缩包预览窗口里直接启动。

GitHub 页面自动提供的 **Source code** 和 **Code → Download ZIP** 是发行仓库文件，不包含完整运行程序与教材资源。请选择上面指定的完整包附件。

## 3. 开始学习

| 系统 | 启动方式 |
| --- | --- |
| Windows | 双击 `start-study.cmd` |
| macOS / Linux | 在 `zhixu-cpa` 文件夹打开终端，运行 `sh start-study.sh` |

macOS 上也可以打开「终端」，输入 `cd` 和一个空格，把解压后的文件夹拖进终端窗口，按回车后再执行启动命令。

首次启动需要联网，程序会自动准备所需文件。请等待启动完成，并在学习时保持启动窗口打开。

浏览器打开后，点击 **「开始学习」**。如果没有自动打开，手动访问：

**[http://127.0.0.1:3000/login](http://127.0.0.1:3000/login)**

**到这里就可以学习了，无需注册账号。来源验证是可选功能，普通使用不用阅读那份文档或运行验证命令。**

进入「科目与章节」看知识点和随堂例题，进入「在线做题」选择轻一、轻二题组。

## 下次继续与结束使用

以后再次运行同一个启动文件即可，已有学习记录会保留。

学习时保留启动窗口。关闭浏览器不会停止程序；关闭启动窗口，或在终端按 `Ctrl+C`，可以结束服务。服务停止后，本机页面会暂时无法访问，重新启动即可。

在线体验与本机学习记录是分开的。本机记录不会自动同步到网站或另一台电脑。

## 备份、升级与换电脑

<summary>需要备份或升级时，再展开查看</summary>

需要保留的两个目录是：

| 目录 | 用途 |
| --- | --- |
| `.wrangler/study-state` | 本机学习数据与记录 |
| `resources` | 完整包附带的教材资源 |

备份步骤：

1. 先停止服务，确认启动窗口已关闭或终端程序已退出。
2. 将 **`.wrangler/study-state` 整个目录**复制到备份位置，不要只挑其中某个数据库文件复制。
3. 一并保留 **`resources` 整个目录**。希望操作更简单，也可以在停止服务后复制整个 `zhixu-cpa` 文件夹。

找不到 `.wrangler` 时，打开文件管理器的「显示隐藏文件」。macOS 可以按 `Command + Shift + .` 切换显示。

换电脑时，先安装 Node.js、解压官方完整包，再把备份的 `.wrangler/study-state` 放回相同位置。恢复前保持服务关闭，并先保存目标电脑上已有的记录。

### 升级版本

升级前先停止程序并备份，**保留 `.wrangler/study-state` 与 `resources`**。

推荐将新版完整包解压到新文件夹，然后把旧版的 `.wrangler/study-state` 整个复制到新版相同位置。新版完整包已带有 `resources` 时，使用新版随包资源，无需用旧资源覆盖；旧版资源也先保留在备份中。

使用新版启动文件，确认原有记录能够打开后，再整理旧文件夹。

## 常见问题

| 情况 | 可以这样处理 |
| --- | --- |
| 提示需要 Node.js | 安装 22.13 或更高版本，关闭窗口后重新启动。 |
| 首次安装失败 | 确认网络连接正常，再运行启动文件。 |
| 提示资源缺失 | 确认下载的是完整包，并已完整解压 `resources`。 |
| 浏览器没有自动打开 | 保持启动窗口运行，手动访问本机默认地址。 |
| 提示 3000 端口已被占用 | 先检查是否已有一份知序 CPA 正在运行。 |

仍有问题，可以通过 [问题反馈](https://github.com/carrotProgrammer/zhixu-cpa/issues/new?template=bug-report.yml) 提交系统、版本、复现步骤和相关报错。

仅在想核对他人转发的软件包时，按需查看 [来源核对（可选）](source-verification.md)。
