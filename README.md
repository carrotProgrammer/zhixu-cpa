# 知序 CPA

**免费给备考的人用：看知识点、刷题、看解析，再把错题复习一遍。**

支持 **会计、税法、经济法**，包含轻一、轻二练习。下载到自己的电脑后，可以保留作答与复习记录。

**[🌐 先在线体验](https://zhixucpa.cn/preview)** · **[📦 下载本地完整版](https://github.com/carrotProgrammer/zhixu-cpa/releases/latest/download/zhixu-cpa-full.zip)**

在线学习无需安装、无需账号。作答进度、成绩、错题和随堂例题记录只保存在你自己的浏览器，刷新后可以继续，不上传到网站的学习数据库。

在[「我的记录」](https://zhixucpa.cn/preview/records)可以导出备份；换设备时再导入。清除网站数据或使用无痕模式可能丢失记录，请定期备份。在线版仍需联网加载学习内容；想在自己的电脑上运行网站，可下载本地完整版。

## 怎么开始用

1. **首次使用**：安装 [Node.js 22.13 或更高版本](https://nodejs.org/)，已有符合版本的可以跳过。
2. **下载并解压**：[点击下载完整版](https://github.com/carrotProgrammer/zhixu-cpa/releases/latest/download/zhixu-cpa-full.zip)，打开里面的 `zhixu-cpa` 文件夹。
3. **启动**：Windows 双击 **`start-study.cmd`**；macOS / Linux 在该文件夹打开终端，运行 **`sh start-study.sh`**。
4. 等浏览器自动打开，点击 **「开始学习」**。

首次启动需要联网，程序会自动准备所需文件，请稍等并保持启动窗口打开。以后再次打开同一个启动文件，就可以接着学。

**正常使用无需阅读来源验证文档，也无需输入任何验证命令。** 遇到启动问题再看 [使用帮助](docs/getting-started.md)。

> 下载请选择上面的「本地完整版」。GitHub 的绿色 Code 按钮和 Source code 附件只包含这个仓库的说明文件。

## 从知识点，到下一次复习

- **读原书知识**：按科目、章节和小节阅读图片，保留原有表格、公式与排版。
- **随学随练**：知识点对应位置提供随堂例题与案例，配合作答、阅读思考和解析查看。
- **继续做题**：章后同步练习与题库练习衔接，当前题库共 **4,264 道题**。
- **回头巩固**：在本地程序中查看作答记录、错题与复习内容，下次接着学。

## 记录留在自己的电脑

再次运行同一个启动文件，已有记录会保留。升级、换电脑前，请先按 [备份说明](docs/getting-started.md#备份升级与换电脑) 保留学习记录。
